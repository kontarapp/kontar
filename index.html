Integrações

Tudo que o ERP precisa pra se integrar ao Kontar: endereço da API, token, documentação, conector e log
Endereço da API
https://southamerica-east1-kontar-e2650.cloudfunctions.net/api/v1

Teste rápido sem token: GET /ping. Com token: GET /eu devolve o cliente.

Token de integração (ERP)

O ERP envia este token no cabeçalho Authorization: Bearer. Gerar um novo invalida o anterior.

Documentação

Manual completo da API pra entregar ao desenvolvedor do ERP: rotas, exemplos, códigos de erro e o que o ERP precisa implementar.

Baixar PDF Abrir no navegador
Guia rápido para o ERP
  1. Listar os balanços abertos da loja: GET /balancos?loja=X&status=aberto
  2. Enviar o catálogo com estoque, custo e venda: PUT /balancos/{id}/catalogo
  3. Acompanhar até o status virar encerrado: GET /balancos/{id}
  4. Buscar a contagem e confirmar o recebimento: GET /balancos/{id}/contagem e POST /balancos/{id}/contagem/confirmar

Alternativa: o ERP cria o balanço (POST /balancos com refErp) e o Kontar espelha. Tudo detalhado na documentação.

Conector ERP (instalador)
Em desenvolvimento

Programa instalado no servidor central do cliente, pra ERPs que não chamam a API sozinhos. Ele lê o cadastro e o estoque do banco do ERP, envia o catálogo pro balanço e grava a contagem de volta no ERP quando o balanço encerra.

O instalador vai pedir: o token desta tela, o endereço e usuário do banco do ERP e o mapa das lojas. Quando estiver pronto, o download aparece aqui.
